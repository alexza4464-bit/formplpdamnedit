Formulir Data Laporan PLP

Naskah rapi, format sesuai kampus, sitasi anti pusing. Isi sebisanya, tekan “Buat ringkasan”, lalu kirim langsung ke WhatsApp DAMNEDIT. Data yang dikosongkan akan ditandai kosong, tidak diisi perkiraan.

Formulir ini memuat NIP/NUPTK. Data tidak disimpan di server mana pun. Data dienkripsi di perangkatmu sebelum dikirim. Data baru terkirim ketika kamu menekan tombol kirim di WhatsApp, dan hanya ke admin DAMNEDIT.
1. Identitas mahasiswa
2. Pejabat dan nomor identitas
3. Masa PLP
4. Jadwal dan materi mengajar

Satu kotak per pertemuan. Jumlah hadir dan catatan boleh dikosongkan, tetapi isi sesuai kejadian sebenarnya jika ada.

5. Profil sekolah

Isi singkat saja, sebisanya. Yang belum ada boleh dikosongkan.

6. Lembar observasi (Lampiran 1 dan 2)

Pilih sesuai pengamatan sebenarnya. Biarkan “—” bila belum diamati; tidak akan dianggap “Ya”.

7. Log bimbingan (Lampiran 14)
8. Refleksi berkala (Lampiran 15)
9. Catatan tambahan
